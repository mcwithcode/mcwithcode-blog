# 【統合版マイクラ 1.20.120～】ワールドデータとアドオンの保存場所変更について

Windows 版の統合版マインクラフトが 1.20.120 にアップデートされたことにより、ワールドデータの保存場所とアドオンの保存場所が変更されました。

## ワールドデータの保存場所
これまでの保存先👇️

```txt
C:\Users\<user-name>\AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds
```

**1.20.120 以降の保存先👇️**

```txt
C:\Users\<user-name>\AppData\Roaming\Minecraft Bedrock\Users\<謎の数字の羅列>\games\com.mojang\minecraftWorlds
```

自動でアップデートすると、元フォルダは移行済みになっているはずです。

## アドオンの保存場所
これまでの保存先👇️

```txt
C:\Users\<user-name>\AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang
```

上記ディレクトリの中にある `behavior_packs` や `resource_packs` が以前までの保存先です。

</br>

**1.20.120 以降の保存先👇️**

```txt
C:\Users\<user-name>\AppData\Roaming\Minecraft Bedrock\Users\<謎の数字の羅列>\games\com.mojang
```

この保存先にも同じく `behavior_packs` や `resource_packs` があります。そこにアドオン関連のファイルを移行しましょう。

ただ、開発中のアドオンについては、謎の数字の羅列にある `development` 系のフォルダに入れても読み込まれませんので、Users ディレクトリまで戻ったところにある、`Shares` フォルダに移動します。詳しい保存先は次のセクションを参照してください。

## 開発中のアドオンの保存場所
ローカル環境等で開発中のアドオンについてはディレクトリが異なり、"Shared" のほうになるようです。

</br>

これまでの保存先👇️

```txt
リソースパック
C:\Users\<user-name>\AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\development_resource_packs

ビヘイビアパック
C:\Users\<user-name>\AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\development_behavior_packs
```

**1.20.120 以降の保存先👇️**

```txt
リソースパック
C:\Users\takun\<user-name>\Roaming\Minecraft Bedrock\Users\Shared\games\com.mojang\development_resource_packs

ビヘイビアパック
C:\Users\takun\<user-name>\Roaming\Minecraft Bedrock\Users\Shared\games\com.mojang\development_behavior_packs
```

以上のような変更がありましたので、例えば Minecraft Creator Tools で作成したアドオンのプロジェクトの設定ファイル `.env` も少しいじる必要があります。

```.env
PROJECT_NAME="<プロジェクト名>"
MINECRAFT_PRODUCT="Custom"
CUSTOM_DEPLOYMENT_PATH="C:\Users\<user-name>\AppData\Roaming\Minecraft Bedrock\Users\Shared\games\com.mojang"
```
